## Key vocabulary (in your own words)

- repository: Place where you can store your files and projects
- commit: Saves your changes in your local repository
- branch: Lets you work on changes without affecting the main project
- push / pull: Push uploads your commited changes to the remote repository or in your github  while Pull downloads the latest changes from remote repository
- pull request: Request to review and merge your changes into the project
- merge conflict: Happens when two different changes are made to the same part of files and git cant decide which change to keep
